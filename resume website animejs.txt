# AI Prompt: Senior Frontend Developer - Animated Resume Website

## Project Overview
Build an engaging, fully client-side animated resume website using Anime.js with sophisticated animations and interactive elements.

## Technical Specifications

### Core Requirements
TECH STACK: HTML5, CSS3, JavaScript (ES6+), Anime.js
ANIMATION: Anime.js for all animations and transitions
RESPONSIVE: Mobile-first design approach
PERFORMANCE: Optimized animations (60fps target)
ACCESSIBILITY: WCAG 2.1 AA compliant

### Feature Implementation Details

#### 1. Animated Timeline System
Timeline Data Structure:
- Work history entries with company, position, period
- Education history with institution, degree, period
- Skills and achievements for each entry
- Interactive date markers and connections

#### 2. Animation Sequences
Planned Animation Scenarios:
- Hero section: Typing effect for name/title
- Skill bars: Progressive filling with percentage reveal
- Timeline entries: Staggered slide-in with fade effects
- Portfolio items: 3D flip on hover
- Contact form: Input field focus animations

#### 3. Interactive Elements
Hover Effect Classes:
- .hover-lift: TranslateY transform on hover
- .hover-glow: Box-shadow glow effect
- .hover-scale: Smooth scaling transformations
- .hover-color: Color transition effects

## Key Technical Decisions

### Animation Strategy
Animation Configuration:
- Duration: 1000ms base
- Easing: easeOutElastic for bounce effects
- Stagger delays for sequential animations
- Opacity and transform-based animations for performance

Scroll-triggered animations using Intersection Observer API with threshold-based triggers for smooth user experience.

### Responsive Design Approach
CSS Variables for Consistent Animations:
- --animation-duration: 0.8s (mobile) / 1s (desktop)
- --stagger-delay: 0.1s (mobile) / 0.15s (desktop)
- --easing-primary: cubic-bezier(0.25, 0.46, 0.45, 0.94)
- --easing-bounce: cubic-bezier(0.68, -0.55, 0.265, 1.55)

Mobile-first media queries with animation timing adjustments for different viewports.

## Senior Developer Notes
Focus on storytelling - use animations to guide the user through your professional journey. Prioritize performance - animations should enhance, not hinder, the user experience. Maintain accessibility - ensure animations don't exclude users with disabilities.

Start with the mobile experience - design animations that work well on touch devices. Use CSS transforms for better performance than layout-changing properties.

Implement reduced motion preferences - respect users who prefer less animation through @media (prefers-reduced-motion: reduce).

Consider the narrative flow - time animations to create a compelling story of your career progression rather than random visual effects.

The resume should feel like an interactive portfolio that demonstrates both your technical skills and your design sensibility through thoughtful, purposeful animations.
